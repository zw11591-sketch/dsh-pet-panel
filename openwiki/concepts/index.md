# Files

- [A2A Protocol Surface](a2a-protocol.md) - The Agent-to-Agent integration on dsh-pet-panel — the per-profile a2a-agents.json card + external-agent registry backed by A2AConfigGateway (get / setCard / upsertAgent / delete / checkAgents) over the Typert remote, the model-facing a2a_list_agents / a2a_call outbound tools with the exact→normalized→substring→Levenshtein resolution chain and candidate closure on no-unique-match, and the inbound /.well-known/agent-card.json + /a2a JSON-RPC message/send endpoints that run the full dsh agent loop with contextId↔sessionId mapping, fail-closed approval, and session persistence — plus the TeamGateway reuse of the same registry.
- [Per-Profile Data Isolation](per-profile-isolation.md) - The invariant that each dsh profile sees only its own skills, MCP servers, A2A registrations, and team/team-chat data, because dsh-pet-panel derives the active profile from process.argv and resolves every data surface under $DSH_HOME/profiles/<name>/.
